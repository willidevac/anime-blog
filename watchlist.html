Woher die Daten kommen

Anime-Daten werden über die Jikan API geladen. Lokale Fallbacks sorgen dafür, dass die Watchlist auch bei API-Ausfall lesbar bleibt. AniList bleibt die bessere Datenquelle fuer einen spaeteren Proxy- oder Build-Step, ist aber direkt im Browser per CORS blockiert. News-Texte werden nicht automatisch kopiert.
